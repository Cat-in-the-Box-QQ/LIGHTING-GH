เข้าสู่ระบบ

เข้าสู่ระบบด้วยบัญชี Supabase ของทีมงาน — admin จะเห็นเครื่องมือจัดการข้อมูลและสิทธิ์ ส่วน crew จะเห็นข้อมูลบัญชีของตัวเองและปุ่มจองอุปกรณ์

เข้าสู่ระบบแล้ว

บัญชี: -
สถานะการตรวจสอบข้อมูล
คำแนะนำการใช้งาน
  1. เปิดหน้า Equipment หรือ Accessories แล้วกดดูรายละเอียดของรายการที่ต้องการ
  2. สิทธิ์ admin จะเห็นปุ่ม แก้ไข / ซ่อน / ลบ ใน popup รายละเอียด ส่วน crew จะไม่เห็นปุ่มเหล่านี้
  3. ปุ่ม + เพิ่ม Fixture และ + เพิ่ม Accessory อยู่ในส่วนจัดการข้อมูลของหน้านี้
  4. ดูกล่อง การเชื่อมต่อ Supabase ด้านบนสุดของหน้านี้ก่อนเสมอ — ถ้าขึ้นป้ายสีเขียว “เชื่อมต่อ Supabase แล้ว” ข้อมูลที่บันทึกจะเขียนลงฐานข้อมูลกลางที่ใช้ร่วมกันทุกเครื่อง
  5. ถ้าขึ้นป้ายสีเหลือง “โหมด local (fallback)” แปลว่า Supabase ใช้ไม่ได้ชั่วคราว ข้อมูลจะถูกลงไว้ในเครื่องนี้ก่อน กด ตรวจซ้ำ เพื่อลองเชื่อมต่อใหม่
  6. กดที่กล่อง Verified / Partial / Pending เพื่อดูรายการในสถานะนั้นแบบ Popup
จัดการข้อมูล
ข้อมูลหลักรันจาก Supabase เมื่อแผงสถานะด้านบนขึ้นป้ายสีเขียว — การ export ใช้สำหรับสำรองข้อมูลหรือดึง snapshot ออกมา
ทีมงานและสิทธิ์
ใคร login ได้ และใครแก้ไขข้อมูลได้
กำลังโหลดรายชื่อทีมงาน...
เพิ่มทีมงาน: สร้างบัญชีที่ Supabase → Authentication → Users → Add user (ติ๊ก Auto Confirm User) แล้วแถวจะโผล่ที่นี่อัตโนมัติเป็นสิทธิ์ crew และใช้งานได้ทันทีโดยไม่ต้องกดอนุมัติ — กดแก้ไขเพื่อตั้งรหัสประจำตัว หรือเลื่อนสิทธิ์เป็น admin
เว็บสร้างบัญชี login เองไม่ได้ เพราะ publishable key ไม่มีสิทธิ์จัดการ Authentication และปิดการสมัครเองไว้แล้ว จึงมีเฉพาะ admin ที่สร้างบัญชีใน Dashboard ได้
การนำคนออกใช้ปิดใช้งานแทนการลบ จึงกดคืนได้ทันที
นี่คือบัญชีของคุณ — สิทธิ์ crew ใช้จองอุปกรณ์ได้อย่างเดียว จึงไม่เห็นปุ่มแก้ไขข้อมูลและไม่เห็นรายชื่อทีมงานคนอื่น
ปุ่ม จอง ท้ายชื่อจะกดได้เมื่อระบบจองพร้อมใช้งาน
ถ้าต้องการสิทธิ์แก้ไขข้อมูล ให้ติดต่อ admin
