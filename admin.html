Admin Access

หน้านี้ใช้สำหรับปลดล็อกสิทธิ์ Admin เพื่อแก้ข้อมูลจากหน้า Detail และหน้ารายการ

Admin Mode เปิดใช้งานแล้ว

ตอนนี้ปุ่ม “แก้ไข” จะปรากฏในหน้า Detail ของอุปกรณ์และ Accessories
สถานะการตรวจสอบข้อมูล
คำแนะนำการใช้งาน
  1. เปิดหน้า Equipment หรือ Accessories แล้วกดดูรายละเอียดของรายการที่ต้องการ
  2. เมื่ออยู่ใน Admin Mode จะเห็นปุ่ม แก้ไข / ซ่อน / ลบ ใน popup รายละเอียด
  3. ปุ่ม + เพิ่ม Fixture และ + เพิ่ม Accessory อยู่ในส่วนจัดการข้อมูลของหน้านี้
  4. บันทึกการแก้ไข แล้วตรวจผลได้ทันทีในหน้าเดิม
  5. กดที่กล่อง Verified / Partial / Pending เพื่อดูรายการในสถานะนั้นแบบ Popup
